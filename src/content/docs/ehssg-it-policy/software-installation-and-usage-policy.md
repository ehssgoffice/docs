## Software Installation
<div class="language-block bur">
အဖွဲ့အစည်းကွန်ပြူတာများတွင် ဆော့ဝဲများကို အိုင်တီဝန်ထမ်းတစ်ဦး၏ အကူအညီ (သို့) ထောက်ခံချက်ဖြင့်သာထည့်သွင်းနိုင်သည်။

လိုအပ်သည့်ဆော့ဝဲ မိမိကွန်ပြူတာတွင်မရှိလျှင် အိုင်တီဝန်ထမ်းတစ်ဦးထံ တောင်းဆိုနိုင်သည်။

အခမဲ့ဆော့ဝဲပင်ဖြစ်စေကာမူ အိုင်တီဝန်ထမ်းတစ်ဦး၏အကူအညီ (သို့) ထောက်ခံချက်မပါဘဲ ထည့်သွင်းခြင်းမပြုရ။

ဆော့ဝဲလိုင်စင်များကို စီမံ/လူ့စွမ်းအားအရင်းအမြစ်ဌာနမှ စီမံခန့်ခွဲပါမည်။

မူပိုင်ခွင့်ချိုးဖောက်ပြီး ခိုးယူအသုံးပြုသည့်ဆော့ဝဲများ ထည့်သွင်းခြင်းကို တင်းကျပ်စွာတားမြစ်ထားသည်။
</div>
<div class="language-block eng">
Software installation can only be done through assistance/approval of an IT staff.

Employees must request necessary software through the IT department.

Even free software should not be installed without an IT staff's assistance/approval.

Software licenses will be managed by the Admin/HR department.

Installation of illegal pirated software is strictly prohibited.
</div>

## Software Usage
<div class="language-block bur">EHSSG ကပေးအပ်ထားသည့် ကွန်ပြူတာများတွင်ထည့်သွင်းထားသည့် ဆော့ဝဲများကို အဖွဲ့အစည်းနှင့်သက်ဆိုင်သည့်လုပ်ငန်းများအတွက်သာ အသုံးပြုရပါမည်</div>
<div class="language-block eng">Software installed on EHSSG provided devices should only be used for the organization's related purposes</div>

Logistics Management Information System ဟာ Information Portal ထဲက ဆေးနှင့်ဆေးပစ္စည်းများ သယ်ယူပို့ဆောင်ဖြန့်ဝေခြင်း အချက်အလက်များ စီမံခန့်ခွဲနိုင်မယ့် အပလီကေးရှင်းဖြစ်ပါတယ်။
LMIS Application ကိုအသုံးပြုဖို့ လိုတာတွေကတော့

- ကွန်ပြူတာ (သို့) တက်ဘလက်
- အင်တာနက်
- အင်တာနက်ကြည့်ရန် browser (Chrome ၊ Brave ၊ Edge စသည်)

## Sign-in ဝင်ခြင်း

Application ကိုဖွင့်ရမယ့်လိပ်စာ၊ Sign-in ဝင်ရမယ့် Email ၊ Password တို့ကို ဦးစွာရရှိထားရပါမယ်။ browser မှာ လိပ်စာရိုက်ထည့်ပါ။

:::note
Application လိပ်စာ၊ Login email နဲ့ password တို့ကို သက်ဆိုင်ရာတာဝန်ရှိသူတွေမှတဆင့် မျှဝေပေးမှာဖြစ်ပါတယ်
:::

Email နဲ့ Password တို့ကိုရိုက်ထည့်ပါ။ Remember me ကိုအမှန်ခြစ်ခဲ့မယ်ဆိုရင် နောက်ပိုင်း sign-in ဝင်တဲ့အခါ email နဲ့ password ပြန်ရိုက်ထည့်စရာမလိုတော့ဘဲ အလိုအလျောက် sign-in ဝင်ပေးပါမယ်။ Email နဲ့ password ထည့်ပြီးရင် Sign in ခလုတ်ကိုနှိပ်ပါ။

## ဦးစွာထည့်သွင်းရမည့် စာရင်းများ

Application စသုံးပြီဆိုတာနဲ့ စာရင်းသွင်းရမှာ နှစ်ခုရှိပါတယ်။

(၁) ပစ္စည်းစာရင်း (Item list)

(၂) စတိုစာရင်း (Warehouse list)

ဒီစာရင်းနှစ်ခုအရင်ရှိထားမှ စတင်အသုံးပြုနိုင်မှာဖြစ်ပါတယ်။ ပစ္စည်းစာရင်းကို LMIS user ဘက်နဲ့ LMIS admin ဘက်နှစ်ခြမ်းစလုံးမှာ သွင်းနိုင်ပါတယ်။ စတိုစာရင်း (warehouse list) ကိုတော့ LMIS admin ဘက်အခြမ်းမှာပဲ သွင်းနိုင်မှာဖြစ်ပါတယ်။

[ပစ္စည်းစာရင်း (Item list) သွင်းပုံ ဆက်လက်ဖတ်ရှုရန်](my-inventory-settings#item-list)

[စတိုစာရင်း (Warehouse list) သွင်းပုံ ဆက်လက်ဖတ်ရှုရန်](lmis-admin-settings#warehouse-list)
